# 🧰 Банк мини-сервисов

Живая версия: https://vzaimno.streamlit.app/

Одно приложение Streamlit — каталог маленьких готовых сервисов. На главной карточки с фильтром по разделам, слева меню, на каждой странице кнопка «← Все сервисы». У каждого сервиса свой адрес, так что ссылкой можно поделиться сразу на нужный.

| Раздел | Сервис | Адрес | Что делает |
|---|---|---|---|
| Учёба | 📚 Тренажёр к экзамену | `/trener` | Вопросы по одному, счёт и разбор ошибок. Готовые наборы («Наука», «Столицы», «Устный счёт») или свои вопросы строками «вопрос = ответ». |
| Учёба | 🗳️ Голосовалка | `/golos` | Ведущий видит QR-код для зала и живой итог, участники голосуют с телефонов. Голосование можно завершить. |
| Деньги | 💰 Копилка | `/kopilka` | Когда накоплю на цель или сколько откладывать в неделю, чтобы успеть к дате. |
| Компания | 🚶 Когда гуляем? | `/kogda` | Каждый отмечает свободные часы, сервис находит время, которое подходит большинству, и рисует тепловую карту недели. |
| Компания | 🤝 Договорились | `/dogovorilis` | Когда, где и чем займёмся: каждый предлагает варианты, все голосуют. |
| Тайные решения | 💌 Взаимно? | `/vzaimno` | Тайный вопрос на двоих: итог «да», только если оба ответили «да». |
| Тайные решения | ✉️ Конверт | `/konvert` | Группа тайно кладёт ответы в конверт, открывается только итог: порог, совпадения, общая картина, все ответы разом или зона сделки. |

## Как устроено

- `app.py` — каталог (`CATALOG`), меню (`st.navigation`) и главная страница.
- Каждый сервис — страница `<имя>.py` с функцией `main()` и константой `PAGE`. Если сервису нужно что-то хранить, рядом лежит `<имя>_db.py` со своим файлом SQLite.
- `common.py` — общие помощники: ссылки-приглашения на нужную страницу, даты, склонения, суммы в рублях.

Чтобы добавить сервис, положи рядом его страницу и допиши одну строку в `CATALOG`.

## Запуск у себя

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация на Streamlit Community Cloud

1. Залей эту папку в репозиторий на GitHub.
2. На [share.streamlit.io](https://share.streamlit.io) нажми **Create app**, выбери репозиторий, ветку `main` и файл `app.py`.
3. В **Advanced settings** можно выбрать адрес вида `mini-servisy.streamlit.app`.

Если ссылки-приглашения получаются неправильными, задай в **Settings → Secrets** строку `PUBLIC_URL = "https://твой-адрес.streamlit.app/"`.

## Что важно знать

- Данные хранятся в файлах SQLite (`golos.db`, `kogda.db` и т. д.) внутри контейнера. На бесплатном Streamlit Cloud они обнуляются при перезапуске, обновлении кода или после долгого простоя приложения.
- Тренажёр и копилка ничего не хранят: всё живёт во вкладке браузера.
- В голосовалке голос привязан к вкладке, а не к человеку. Кто откроет ссылку в новой вкладке, сможет проголосовать ещё раз — для класса этого достаточно, для серьёзных выборов нет.
