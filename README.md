# 💌 Взаимно?

Тайный вопрос на двоих. Создаёшь вопрос, например «Хочешь, чтобы наши отношения продолжались?» или «Идём на второе свидание?», и получаешь две ссылки: свою и для партнёра.

- Каждый отвечает «да» или «нет» по своей ссылке и не видит ответа другого.
- Итог появится, когда ответят оба. Изменить ответ нельзя.
- Оба «да» — обоим приходит «да». Хотя бы одно «нет» — обоим приходит «нет», и текст итога у обоих одинаковый.
- Ответивший «нет» так и не узнает ответ партнёра. Ответивший «да» поймёт, что партнёр против, но его «да» останется тайной.
- Как только итог готов, сами ответы стираются: в базе остаётся только итог.

## Запуск у себя

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация на Streamlit Community Cloud

1. Залей эту папку в репозиторий на GitHub.
2. На [share.streamlit.io](https://share.streamlit.io) нажми **Create app**, выбери репозиторий, ветку `main` и файл `app.py`.
3. В **Advanced settings** можно выбрать адрес вида `vzaimno.streamlit.app`.

Если ссылки для партнёра получаются неправильными, задай в **Settings → Secrets** строку `PUBLIC_URL = "https://твой-адрес.streamlit.app/"`.

## Что важно знать

- Данные хранятся в файле SQLite внутри контейнера. На бесплатном Streamlit Cloud он обнуляется при перезапуске, обновлении кода или после долгого простоя приложения.
- Пока второй не ответил, ответ первого лежит в базе, и владелец сервиса технически может его увидеть.
- Создатель вопроса знает обе ссылки. Если он ответит за партнёра, это будет видно: партнёр откроет ссылку и увидит, что ответ уже дан.
